Figma 기획 화면 1개를 이 프로젝트의 API로 구현하는 작업을 **스텝 게이트 방식**으로 구동한다.

> **정본은 이 파일이 아니라 [피그마_기반_기능구현_가이드.md](../../docs/개발가이드/피그마_기반_기능구현_가이드.md).** 이 커맨드는 그 가이드를 로드하고 절차대로 몰아가는 얇은 오케스트레이터다. 스텝별 판정 기준·Figma 접근 방법·되돌림 규칙은 전부 가이드가 정본 — 여기 복제하지 않는다.
>
> 이 가이드는 이 프로젝트에 Figma 연동 실사례가 아직 없는 상태에서 미리 작성한 것이다. 처음 실제로 화면 하나를 진행하면서 가이드의 맞지 않는 부분을 고친다.

## 인자 (`$1`)

- **`<Figma URL 또는 node-id>`** → 그 화면으로 **0단계(대상확정)부터** 시작
- **`continue`** → 현재 화면의 마지막 승인 게이트 다음 스텝부터 이어서
- **`status`** → 현재 화면이 어느 스텝/게이트인지, 미승인·확인필요 항목 요약만 출력(진행 안 함)

## 착수 시 (필수 선행)

1. **가이드 탐독** — [피그마_기반_기능구현_가이드.md](../../docs/개발가이드/피그마_기반_기능구현_가이드.md) 전체를 읽는다.
2. **Figma 접근 확인** — 가이드 §4 참고. MCP 미인증이면 `/mcp` 안내. 쿼터 소진이나 인증 불가 시 스텝을 건너뛰지 않고 화면 캡처를 요청해 진행한다.

## 구동 규칙

- 스텝 순서: `0 대상확정 → 1 기획추출 → 2 구현설계 → 3 구현 → 4 검증` (가이드 §1 — 레거시/프론트엔드가 없어 레거시트레이스·교차매핑 단계는 없음).
- 모든 스텝 끝에 ✋STOP 게이트. 진짜 결정지점(범위 제외/보류 판단, 설계 트레이드오프)은 AskUserQuestion, 확인만 필요한 스텝은 "산출물 제시 → 다음 갈까요?" 단순 승인.
- 산출물 폴더는 가이드 §5(현재 미확정 — 첫 실행 시 사용자와 확정하고 가이드를 갱신한다).
- 3단계(구현) 완료 후 `./gradlew test` 실행과, 변경된 Controller가 있으면 `/api-doc`으로 Swagger 문서 갱신을 잊지 않는다(가이드 §3).
- 각 스텝 종료 시 가이드 §7 형식으로 다음 작업을 안내한다.

## 진행 추적

화면별 폴더에 진행 상태를 남겨 `continue`/`status`가 위치를 파악하게 한다. 없으면 폴더 내 산출물 존재로 추론한다.
