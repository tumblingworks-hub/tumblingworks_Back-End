# 조사 및 벤치마크

## 조사 목적과 범위

공개적으로 접근 가능한 Indie Hackers 홈과 디렉터리 페이지를 대상으로 정보 구조, 시각 계층, 반복 UI, 핵심 사용자 행동을 분석했다. 로그인 뒤 전용 화면·결제·운영자 도구는 이번 구현 범위에서 제외했다.

## 조사 방법

- [Indie Hackers 홈](https://www.indiehackers.com/)의 공개 HTML 구조와 당일 노출 콘텐츠 확인
- [Groups](https://www.indiehackers.com/groups), [Ideas Database](https://www.indiehackers.com/ideas)의 공개 정보 구조 확인
- 공개된 최근 홈 화면 캡처를 보조 자료로 사용해 3열 비율, 색상 계층, 카드 밀도 확인
- 연결 가능한 대화형 브라우저가 없어서 hover, 실제 로그인, 서버 응답을 직접 계측하지는 못함

## 핵심 정보 구조

```text
Global navigation
├─ Topic channels
├─ Brand/Home
├─ Search / notifications / join
└─ Secondary database links

Home
├─ Popular discussion rail
├─ Featured editorial feed
│  ├─ Hero story
│  └─ Secondary story grid
└─ Utility rail
   ├─ Submit / advertise
   ├─ Build Board
   ├─ Mini puzzle
   └─ Newest posts
```

홈의 핵심은 콘텐츠 종류를 페이지로 분리하기보다 한 화면에서 밀도 있게 조합하는 것이다. 중앙 추천 영역은 큰 이미지와 설명을 사용하고, 좌우 레일은 텍스트 중심으로 압축한다. 이 대비가 첫 시선을 중앙에 두면서도 스캔 비용을 낮춘다.

## 시각 패턴

| 항목 | 관찰 | 구현 결정 |
|---|---|---|
| 배경 | 짙은 네이비 단색 계열 | `--ink-*` 토큰 6단계 |
| 포인트 | 형광 녹색, 핑크, 밝은 파랑 | CTA/상태/섹션 의미로 제한 |
| 구분 | 실선보다 점선과 미세 대비 | `--line`, `--line-strong` |
| 레이아웃 | 중앙이 가장 넓은 3열 | 280 / 590 / 310px 기준 |
| 카드 | 넓은 흰 카드보다 배경 위 텍스트 | 불필요한 컨테이너 최소화 |
| 이미지 | 에디터 추천에만 강하게 사용 | CSS 추상 아트로 대체 |
| 글자 | 굵은 제목 + 흐린 메타 정보 | 4단계 텍스트 토큰 |

## 핵심 행동

1. 주제별 인기 글을 빠르게 훑는다.
2. 추천 성공 사례를 읽는다.
3. 게시물에 업보트하거나 댓글 수를 확인한다.
4. Build Board에서 최근 제작 활동을 발견한다.
5. 새 글을 등록하거나 커뮤니티에 가입한다.
6. 제품·아이디어·그룹 데이터베이스로 이동한다.

## 차별화/안전 경계

- 실제 사용자 글과 프로필 사진은 포함하지 않았다.
- 공개 화면의 레이아웃 원리를 학습하되 CSS 일러스트와 샘플 카피를 사용했다.
- `INDIE HACKERS · UI STUDY` 표기로 학습용임을 명확히 했다.
- 실제 출시 전 독자 브랜드, 이용약관, 개인정보 처리, 신고·중재 정책이 필요하다.

## 알려진 조사 한계

- 대화형 브라우저 세션 부재로 실제 DOM 스타일 계산값과 로그인 이후 플로우는 검증하지 못했다.
- 공개 검색 인덱스는 페이지 크롤링 시점에 따라 당일 화면과 일부 콘텐츠가 다를 수 있다.
- 이번 결과는 픽셀 복제보다 구조·시각 리듬·핵심 행동 재현을 우선한다.
